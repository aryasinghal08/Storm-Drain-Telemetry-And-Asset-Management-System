# Storm-Drain-Telemetry-And-Asset-Management-System
## Team
Core 4 Coders

## Project
Storm Drain Telemetry and Asset Management System

## Technologies
- C++
- Data Structures
- Object Oriented Programming

## Data Structures Used

1. Directed Graph
2. Hash Table
3. Circular Queue
4. Max Heap
5. Doubly Linked List

## Project Features

- Display drainage network
- Store sensor readings
- Search sensor data
- Maintain alert queue
- Prioritize flood risk
- Store maintenance records

## Compilation

Open terminal inside the project folder.

Run:

g++ src/main.cpp src/Graph.cpp src/HashTable.cpp src/CircularQueue.cpp src/MaxHeap.cpp src/MaintenanceLog.cpp -o storm

Then run:

./storm

## Windows

If using MinGW:

g++ src/main.cpp src/Graph.cpp src/HashTable.cpp src/CircularQueue.cpp src/MaxHeap.cpp src/MaintenanceLog.cpp -o storm.exe

Then:

storm.exe
